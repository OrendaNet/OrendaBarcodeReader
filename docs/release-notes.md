Initial release of Orenda Barcode Reader.

- Reads approved USB HID keyboard and serial barcode scanners.
- Shows the latest scan and a 25-item in-memory history in a responsive interface.
- Automatically selects the first approved compatible scanner and allows switching when several are approved.
- Stops USB reads shortly after all viewers close the app.
- Uses Edge Console authentication and the install-time `usb:read` grant.
